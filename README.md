# 木刻灵韵 · 智绘年画

基于 Next.js 14、React 18 和 TypeScript 的木版年画文化学习与 AI 辅助创作平台，包含年画创作、年画变装、非遗问答、纹样配色、套印模拟、图片动效、文化地图与灵伴交互。

## 本地启动

```sh
pnpm install
pnpm dev
```

打开 http://localhost:5001 。

## 使用者自行配置密钥

- 火山方舟：在墨韵生花「模型服务配置」中填写自己的 API Token。相关生图、变装和问答接口仅使用当前浏览器会话的配置，不读取开发者的 `.api-config.json`，也不回退到服务器的共用 Token。配置保存在 HttpOnly 会话 Cookie 中；服务端仅为本次接口调用读取，不写入项目文件。可通过 `/api/config` 提交空 Token 清除配置，或清除网站 Cookie。
- 光影新生：在该页面填写自己的火山方舟、阿里云百炼 API Key、业务空间 ID 和地域。页面已有浏览器本地保存功能；共用电脑请清除网站数据。
- 寻迹山河：在地图配置入口填写自己的高德 Web Key 与安全配置。浏览器地图 SDK 必须使用 Web 端凭证，请在高德控制台设置适用的域名限制；不要把服务端私密凭证放入 `NEXT_PUBLIC_*`。
- 未配置密钥时，涉及付费模型的功能需先配置；本地知识展示和不依赖模型的交互仍可使用。
- 线上部署请使用 HTTPS。密钥会经本项目服务端转发给对应模型提供商，请仅在可信的部署实例中填写密钥。

仓库不包含真实密钥、`.env`、用户上传文件、依赖或构建缓存。数据库等部署配置请自行提供，不要将真实凭证提交到 Git。
