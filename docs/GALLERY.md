## 素材来源

| 文件 | 来源及说明 |
| --- | --- |
| workbench / creation / knowledge / dress / heritage / tour / animation | 从当前本地代码启动的页面采集；独立浏览器，无用户登录和真实密钥。 |
| printing-layers | 使用项目内的门神参考图片，实际执行本地图层分离与整合后截图。 |
| companion | 从真实页面开启三维灵伴与交互面板后截图。 |
| dress-reference / dress-result | 参考图片与历史演示录屏中的结果截取；未展示人物输入照片。 |
| door-gods-demo.gif | public/videos/door-gods-reference.mp4 的短片段；预置演示，非本次实时生成。 |
| banner / workflow / architecture | 按当前项目内容新编排的横幅与说明图，提供 PNG 和 SVG 源文件。 |

图片用于解释当前功能，不代表每次生成都有同样效果。请在公开分享或再分发前确认参考素材的授权范围。
