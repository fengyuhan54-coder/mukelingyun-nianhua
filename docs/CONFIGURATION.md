# 密钥配置指南

[返回项目首页](../README.md) · [文档与界面图](GALLERY.md)

本指南对应木刻灵韵当前页面。使用者需要准备自己的服务账号与密钥，平台不附带开发者密钥。无需一次配置所有服务：只配置你准备使用的功能即可。

## 一、每个功能需要什么配置

| 项目功能 | 是否需要密钥 | 到哪里配置 |
| --- | --- | --- |
| AI 对话工作台 | 文化问答、模型辅助创作需要火山方舟；功能导航和部分本地知识回复无需密钥 | 先到 **墨韵生花 → 模型服务配置** 保存自己的火山方舟密钥，再返回工作台。 |
| 墨韵生花 | 火山方舟，需具备所调用生图、视觉与对话模型的权限 | 页面下方 **模型服务配置 → API Token 配置 → 保存**。 |
| 木韵新绘 | AI 生图、参考图分析需要火山方舟；浏览选项无需密钥 | 本页 **API Token 配置 → 保存 Token**；也可使用已在墨韵生花保存的会话配置。 |
| 年画变装 | 火山方舟，用于人像检查、双图生成与风格化处理 | 本页没有独立密钥框；先在 **墨韵生花 → 模型服务配置** 保存，再进入年画变装。 |
| 古筑绘影 | 火山方舟，用于生图与参考图分析 | 页面顶部 **API Token 配置 → 保存 Token**；也可使用已有会话配置。 |
| 遗韵拾光 | 阅读内置知识无需密钥；模型问答需要火山方舟 | 先在 **墨韵生花 → 模型服务配置** 保存，再回本页提问。 |
| 文脉藏珍 | 纹样浏览、检索、配色及选择同步不需要模型密钥 | 无需配置。进入创作页面后生成作品，才需要对应模型配置。 |
| 墨痕留印 | 本地图像分层、拖拽和叠印不需要外部密钥 | 无需配置，上传图片即可体验。 |
| 光影新生 | AI 画面分析需要火山方舟；一般图片的视频生成需要阿里云百炼 | 本页 **模型与高级设置 → 模型配置**；火山方舟和百炼分别保存，详见第四节。 |
| 寻迹山河 | 真实地图需要高德 Web Key 与安全密钥；图片分析和模型问答需要火山方舟 | 地图在本页 **真实地图尚未配置** 区域填写；火山方舟在墨韵生花配置。 |
| 灵伴相随 | 三维展示、拖动、快捷入口无需模型密钥；模型文化问答需要火山方舟 | 火山方舟在墨韵生花配置；浏览器语音另需麦克风权限与浏览器支持，无独立语音密钥框。 |
| H5 互动体验 | 平台的 H5 入口无需填写模型密钥 | 从侧边栏进入并扫描页面二维码；跳转到独立的互动体验。 |
| 印记长存 / 作品与个人中心 | 本身无需额外模型密钥 | 作品生成所需密钥在相应创作功能配置；部分服务端作品、个人信息与头像接口需要部署者配置数据库，见第七节。 |

## 二、先获取自己的火山方舟密钥

1. 登录 [火山方舟控制台](https://console.volcengine.com/ark)。
2. 选择你的资源项目，在 **API Key 管理** 中创建或复制自己的 API Key。
3. 按所需功能开通可用的模型服务，并确认密钥有访问对应模型的权限。创建密钥本身不等于已获得所有模型权限。
4. 复制密钥完整值，准备粘贴到平台的密码输入框。不要添加 `Bearer`、引号、空格或变量赋值前缀。

项目部分页面将这个凭证标为 **API Token**；请以控制台实际签发的凭证为准。官方说明：[快速入门](https://docs.volcengine.com/docs/ark/quick-start?lang=zh)、[API Key 管理](https://docs.volcengine.com/docs/ark/manage-api-keys?lang=zh)。

## 三、配置创作、变装和问答使用的火山方舟密钥

### 推荐入口：墨韵生花

1. 启动本项目，进入 **AI 对话工作台**。
2. 在左侧 **专业 Skill** 中进入 **墨韵生花**。如当前点击只挂载 Skill，可使用该条目右侧箭头进入页面。
3. 在页面中向下找到并展开 **模型服务配置**。
4. 在 **API Token 配置** 密码框中粘贴自己的火山方舟密钥，点击 **保存**。
5. 保存成功后，可以在同一浏览器、同一站点内进入 **年画变装、木韵新绘、古筑绘影、遗韵拾光**，或返回工作台和灵伴进行相关操作。

这些功能读取当前浏览器的会话配置，不读取开发者的本地密钥文件，也不会自动回退到服务器共用密钥。密钥输入框不回显已保存的真实值，因此重新进入页面时输入框为空，不一定代表配置已丢失。

### 木韵新绘自己的配置入口

进入 **木韵新绘**，在本页 **API Token 配置** 中填写并点击 **保存 Token**。该入口与墨韵生花使用同一站点、同一浏览器会话的配置；无需为每个页面重复申请密钥。

### 古筑绘影自己的配置入口

进入 **古筑绘影**，在页面顶部 **API Token 配置** 区域填写并点击 **保存 Token**。保存后再上传参考图、提取元素或发起生成。

### 年画变装

1. 按推荐入口先保存火山方舟密钥。
2. 进入 **年画变装**，上传清晰的单人人像。
3. 选择平台年画参考，或上传自己的年画参考图；按需使用文脉藏珍同步来的纹样与配色。
4. 发起生成。若提示未配置或无权限，返回墨韵生花重新保存自己的密钥，并核对模型权限。

### 遗韵拾光、工作台、灵伴与寻迹山河的 AI 功能

上述功能的模型问答或图片分析使用同一份火山方舟会话配置。先在墨韵生花保存，再返回原功能。内置资料、部分本地知识回复、三维展示和快捷跳转不需要模型密钥。

## 四、光影新生：单独配置分析与视频服务

**此页面的火山方舟配置与第三节的会话配置是两个独立入口，不会自动同步。**

### A. 配置画面分析用的火山方舟

1. 进入 **光影新生**。
2. 展开 **模型与高级设置**，找到 **模型配置 → 视觉分析：火山方舟**。
3. 输入自己的火山方舟凭证，点击旁边的 **保存**。
4. 再使用 **AI 画面分析** 或动态需求理解等功能。

当前此页面对凭证使用 `ark-` 开头的格式检查。如果官方签发的真实凭证被界面判定为格式错误，请勿手动拼接前缀或使用其他平台的 Key；需要核对该页面与实际凭证格式的兼容性。格式校验或“已保存”也不等于模型调用权限已验证。

不配置火山方舟时，部分动态文字要求可由本地规则整理，但 AI 画面分析不能因此替代为已完成。

### B. 获取阿里云百炼配置

1. 登录 [阿里云百炼控制台](https://bailian.console.aliyun.com/)。
2. 选择准备使用的地域，开通相应服务并确认账号可调用项目使用的视频模型。
3. 在密钥管理中创建或复制自己的 **API Key**。
4. 打开当前 **业务空间详情**，复制 **业务空间 ID（Workspace ID）**，不要用空间名称或账号 ID 代替。
5. 记录同一空间、同一地域对应的 API Key 与 Workspace ID。

官方说明：[获取 API Key](https://help.aliyun.com/zh/model-studio/get-api-key/)、[业务空间管理](https://www.alibabacloud.com/help/zh/model-studio/use-workspace)。

### C. 在光影新生保存视频配置

1. 在 **模型配置** 中找到 **视频生成：阿里云百炼 · wanx2.1-i2v-turbo**。
2. 填入自己的 **百炼 API Key** 和 **业务空间 ID**。
3. 在地域下拉框中选择与这组配置一致的地域，点击 **保存万相配置**。
4. 上传图片、填写动态要求和生成规格，再发起视频生成并等待任务结果。

当前代码使用 `wanx2.1-i2v-turbo` 以及业务空间对应的接入地址。并非下拉框中的每个地域都必然提供该模型；若模型不可用，应先检查账号权限、模型供应和接口适配，不能只切换地域。

**示例例外：** 平台识别到指定门神参考图时，可播放对应的预置演示视频，无需百炼配置；其他图片按模型生成逻辑处理。预置视频不会随着动态描述或规格变化而重新生成。

## 五、寻迹山河：配置真实地图

### 获取高德 Web 凭证

1. 登录 [高德开放平台控制台](https://console.amap.com/dev/key/app)。
2. 在应用管理中创建应用，添加 **Web 端（JS API）** 类型的 Key。
3. 取得该 Key 对应的 **安全密钥 securityJsCode**。
4. 按控制台要求配置允许访问的域名，线上域名与本地调试地址应分别核对。

官方说明：[JS API 准备](https://lbs.amap.com/api/javascript-api-v2/prerequisites)、[安全密钥使用](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)。这里需要 Web 端 JS API 凭证，不能用其他类型的密钥替代。

### 在项目页面填写

1. 进入 **寻迹山河**，找到地图区域的 **真实地图尚未配置** 提示。
2. 在 **Web 端 JS API Key** 中填写自己的 Key。
3. 在 **安全密钥 securityJsCode** 中填写配套的安全密钥。
4. 点击 **保存并加载真实地图**。
5. 地图加载后再搜索地点；使用定位时允许浏览器的位置权限。

地图凭证不代替火山方舟密钥。如果需要在探索过程中分析上传的图片或使用模型问答，还需完成第三节的配置。

## 六、不需要配置密钥的功能怎么使用

- **文脉藏珍**：进入页面浏览纹样与配色，选择元素并同步到创作功能；真正生成图片时再配置火山方舟。
- **墨痕留印**：上传本地图片，点击 **开始分离**，通过 **自动整合**、**分步叠加** 或拖拽操作体验套印。
- **遗韵拾光的知识浏览**：直接查看页面内置的文化资料与工艺内容。
- **灵伴相随的三维交互**：打开灵伴后拖动查看、单击展开快捷入口。浏览器语音功能需要相应支持和授权，不需要在项目里额外填写语音密钥。
- **H5 互动体验**：进入页面并扫描二维码，打开独立的年画互动体验。
- **印记长存及作品管理页面**：浏览、管理功能不需要新申请模型密钥。是否能保存至服务端，取决于所部署版本的数据库环境。

## 七、作品与个人中心的数据库配置（部署者）

部分作品、个人信息及头像接口使用 PostgreSQL。普通使用者不需要把数据库密码填进创作页面。

部署者应在自己的运行环境中设置 `PGDATABASE_URL`，并准备与接口兼容的数据表。不要把真实数据库连接串写入 README、源码或提交记录。火山方舟、百炼和高德的配置不能替代数据库配置；仅填写模型密钥也不代表服务端作品管理已经部署完成。

## 八、配置范围、更换与清除

| 配置 | 保存范围 | 更换或清除方式 |
| --- | --- | --- |
| 共用的火山方舟会话配置 | 当前浏览器、当前站点的 HttpOnly 会话 Cookie | 在配置入口输入新密钥并保存；彻底清除可删除本站 Cookie。 |
| 光影新生的火山方舟与百炼配置 | 当前浏览器的网站本地存储 | 在本页修改并重新保存；清除时删除本站网站数据。 |
| 高德地图配置 | 当前浏览器的网站本地存储 | 重新配置或清除本站网站数据后重新填写。 |

`localhost`、`127.0.0.1` 与线上域名属于不同站点，配置不会自动互通；不同浏览器或不同设备也需要各自配置。浏览器可能恢复会话 Cookie，因此不要把关闭窗口当作可靠的清除方法。

线上使用 HTTPS；只在可信的项目部署实例中填写自己的密钥。模型请求会经本项目后端转发给对应服务商。不要把真实密钥提交至 GitHub，也不要截图发送给他人。

## 九、常见问题

| 提示或现象 | 优先检查 |
| --- | --- |
| 未配置 Token | 是否在正确入口点击保存，当前域名和浏览器是否与保存时相同。 |
| 已保存，但调用失败 | 保存不代表账号权限通过；检查密钥有效性、模型权限、额度和服务地域。 |
| 401 / 403 | 检查凭证、项目或空间权限、访问限制；不要通过添加虚构前缀修改密钥。 |
| 视频生成失败 | 检查百炼 Key、Workspace ID、地域及视频模型可用性。 |
| 地图不显示 | 检查是否为 Web JS API Key、securityJsCode 是否配套、域名限制及网络。 |
| 定位或语音无响应 | 检查浏览器支持、HTTPS 与位置或麦克风权限。 |
| 换了浏览器后要求重新填写 | 属于独立浏览器配置的正常表现。 |
| 模型能用，但作品保存失败 | 检查服务端数据库及表结构，不能通过重填模型密钥解决。 |
